# 支持范围与已知限制

本 fork 新增 Windows / Python 3.12 Tk 界面，启动与已验证范围见 [Windows 适配](WINDOWS.md)。已在 Windows 实机读取额度和重置卡；暂无托盘与 Codex 更新提示。以下原版兼容矩阵和原生界面细节适用于 macOS。

## 环境兼容性

| 项目 | 当前范围 | 验证情况与限制 |
| --- | --- | --- |
| 操作系统 | macOS，使用 Cocoa 桌面界面 | 本地验证环境为 macOS 26.7.1；未建立最低系统版本承诺，较旧 macOS 需自行构建验证 |
| CPU | 在本机构建当前架构 | Intel x86_64 已验证；Apple Silicon arm64 的版本请求有代码支持，但尚未实机验证；不生成 Universal Binary |
| Swift | Xcode Command Line Tools 中的 `swiftc` | 本地使用 Swift 5.3.2 编译通过；不是 Swift Package，无需 `swift package` |
| Python | 构建要求 3.12+，仅使用标准库 | Python 3.12.14 完成构建与离线检查；3.13.2 通过离线 Python 测试，但本机该解释器缺少 CA，不能据此声称已验证联网 |
| 登录方式 | 默认 `~/.codex/auth.json` 中可读的 `tokens.access_token` 与 `tokens.account_id` | 不支持仅 API Key、仅钥匙串、自定义 `CODEX_HOME` 或第三方多账号管理 |
| 套餐 | 接口确实返回所需额度字段的账号 | 未逐一验证 Free、Plus、Pro、Business、Enterprise、Edu 等套餐；不保证所有账号都有重置卡功能 |
| 版本检测 | `/Applications/Codex.app` 与 `/Applications/ChatGPT.app` 中的有效 Codex 稳定版 | 优先最高构建号；不递归扫描、不开启自定义安装位置，不提示 beta |
| 发布形式 | 源码下载、在本机编译 | 没有已验证的通用二进制安装包、签名、公证、Homebrew 或 App Store 分发 |

GitHub Actions 配置了 macOS / Python 3.12 离线检查，但在仓库首次实际运行前，只能视为待验证配置。其他操作系统可以运行部分纯 Python 测试，不代表支持桌面应用。

## 功能边界

| 功能 | 实际行为 | 不包含的能力 |
| --- | --- | --- |
| 剩余额度 | 选择 `primary_window` / `secondary_window` 中周期最长的一个，显示 `100 - used_percent` | 不同时显示两个窗口，不统计本地 token、账单、API 余额或另购 credits；周额度充足不代表短窗口一定可用 |
| 日均预算 | 当前余额除以距重置天数；不足一天显示重置前可用余额 | 不采集历史消耗，不预测还能使用几小时，不按工作日或时区制定计划 |
| 重置卡 | 统计 `available` 且尚未到期的卡片，展示最早到期一张 | 不兑换、不选择、不购买；未知状态字段显示未知，不自动猜测可用性 |
| 卡片提醒 | 不足 24 小时为橙色，不足 3 小时为红色；恰好阈值归入较轻一级 | 无系统通知、声音、邮件或其他推送，窗口隐藏时不主动弹出 |
| 倒计时与日期 | 本地每秒计算；具体时间固定显示 GMT+8 | 时区及语言目前不可配置；依赖本机系统时钟 |
| 刷新 | 启动读取；额度每 60 秒、版本每 3600 秒；手动刷新同时触发两者 | 不是服务端推送；已有同类请求执行时跳过重复请求，不进行额外排队 |
| 版本提示 | 对比稳定构建号并筛选系统版本，保留同一安装的上次成功结果 | 不下载、不安装、不重启 Codex；橙点可能一直保留到下一次成功刷新 |
| 窗口 | 拖动、置顶/取消置顶、隐藏、菜单栏恢复，保存配色和窗口位置 | 不是 WidgetKit 小组件；置顶/隐藏状态不跨启动保存，启动默认显示并置顶；无多实例协调 |
| 启动与退出 | 手动启动；受控退出停止定时器并回收自有读取进程 | 不自动安装登录启动项；强制结束或系统崩溃不保证清理完成 |

不建议同时运行多个副本：它们会各自轮询，并可能共享同一路径的缓存。睡眠期间不保证轮询；唤醒后的恢复和长期驻留仍需进一步实机验证。

## 数据异常时的行为

- 额度失败时，只有能验证为当前 account ID 摘要的缓存才允许回读。无法读取登录文件或账号已变化时，不保证保留画面中的旧账号结果。
- 读取过程中账号发生变化时拒绝发布旧账号数据；切换账号后，画面在下一次读取前可能暂时仍是旧快照，不是实时账号切换通知。
- 数据超过 180 秒，或读取时间比当前时钟超前超过 60 秒时，隐藏日均预算并标记过期。旧额度及卡片仍可能展示，但都只代表上次快照。
- 到达额度重置时间时显示等待刷新，不自动把剩余额度设为 100%。
- 卡片字段失败时显示数量/状态未知，尽可能保留同次成功取得的额度；卡片在本地到期后自动从计数中排除。
- 额度读取等待上限为 40 秒，版本检查为 60 秒；异常时可再进行最多 5 秒缓存回读。子进程终止清理有额外短暂等待，因此不是严格的端到端秒表上限。命令行直接运行 Python 模块没有原生层的整体超时保障。
- 内部接口、登录文件或 `app.asar` 结构变化可能导致读取失败，需要后续适配。缓存数据不是服务可用性或账号权限的证明。

## 维护与验证边界

目前维护当前源码；没有长期支持分支或响应时限承诺。已验证的离线检查与实机手动检查应分开记录，见 [开发说明](DEVELOPMENT.md)。真实注销/重启、实际账号切换、安装新 Codex、Apple Silicon、长时间睡眠、多显示器切换和 VoiceOver 尚未完成系统性验证。

如当前环境不满足支持条件，请先阅读 [README 故障排查](../README.md#常见问题)，再使用脱敏后的最小复现提交 Issue。
